# STM32F103C8T6 参考模板 — 功能说明文档

> 基于寄存器方式开发（标准外设库框架），系统主频 72MHz。本文档说明 `USER/API` 下各模块的引脚分配与可实现功能。

## 引脚占用总览

| 引脚 | 复用模块 | 功能 | 配置 |
|------|---------|------|------|
| PB4 | LED | LINK 指示灯 | 推挽输出 2MHz（默认复用为 JTAG-NJTRST，初始化时已关闭 JTAG 释放该脚） |
| PB5 | LED | M0 指示灯 | 推挽输出 2MHz |
| PB6 | LED | M1 指示灯 | 推挽输出 2MHz |
| PB7 | KEY | 按键输入 | 浮空输入（低电平有效，建议改为上拉输入） |
| PA9 | USART1 | TX 发送 | 复用推挽输出 50MHz |
| PA10 | USART1 | RX 接收 | 浮空输入 |

---

## 1. led（led.c / led.h）— 指示灯控制

**引脚**：PB4=LINK、PB5=M0、PB6=M1，均为推挽输出，初始化后默认低电平（灯灭）。因 PB4 默认为 JTAG 的 NJTRST 引脚，`LED_Config()` 中通过 `AFIO->MAPR` 关闭 JTAG（保留 SW-DP 调试）后作为普通 IO 使用。

| 函数/宏 | 功能 |
|---------|------|
| `LED_Config()` | 使能 GPIOB/AFIO 时钟，关闭 JTAG，配置 PB4/5/6 为推挽输出并输出低电平 |
| `LED_LINK_On/Off/Toggle()` | LINK（PB4）置高 / 置低 / 翻转 |
| `LED_M0_On/Off/Toggle()` | M0（PB5）置高 / 置低 / 翻转 |
| `LED_M1_On/Off/Toggle()` | M1（PB6）置高 / 置低 / 翻转 |
| `LINK(X)` / `M0(X)` / `M1(X)` | 宏，`X=1` 输出高电平，`X=0` 输出低电平 |

---

## 2. key（key.c / key.h）— 按键检测

**引脚**：PB7，浮空输入。按键电路为"按键接地"型，按下时引脚为低电平（低电平有效）。

| 函数/宏 | 功能 |
|---------|------|
| `KEY_Config()` | 使能 GPIOB 时钟，配置 PB7 为输入模式 |
| `KEY_GetState()` | 返回引脚原始电平（1=高，0=低），无消颤，适用于轮询电平或中断状态判断 |
| `KEY_GetVal()` | 阻塞式按键检测：检测到低电平后延时 20ms 消颤确认，再等待按键释放，返回 1 表示一次有效按键 |
| `KEY` | 宏，读取 PB7 电平，如 `if (KEY == 0)` 表示按下 |

---

## 3. usart（usart.c / usart.h）— 串口通信

**引脚**：PA9=TX（复用推挽 50MHz）、PA10=RX（浮空输入）。数据格式 8N1，波特率由参数指定（推荐 115200 / 9600，按 fPCLK2=72MHz 计算 BRR）。

**接收机制**：中断方式（RXNE 逐字节 + IDLE 空闲帧判定），接收数据存入全局结构体 `USART1_RecvData`（256 字节缓冲区 + 帧完成标志 `flag` + 字节计数 `count`），一帧接收完成后自动回显。主循环用法：

```c
if (USART1_RecvData.flag) {
    // 处理 USART1_RecvData.buffer，长度 USART1_RecvData.count
    memset(&USART1_RecvData, 0, sizeof(USARTRecvData)); // 处理完清零
}
```

| 函数 | 功能 |
|------|------|
| `USART1_Config(brr)` | 初始化 USART1：GPIO、8N1 格式、NVIC（抢占优先级 0）、波特率计算并使能 |
| `USART1_SendC(data)` / `USART1_SendByte(Byte)` | 发送单字节（阻塞等待 TXE 与 TC） |
| `USART1_SendStr(data, len)` | 定长数组发送（len 为 8 位） |
| `USART1_SendBuffer(buffer, len)` | 缓冲区发送（len 为 16 位，可发送 >255 字节） |
| `USART1_SendString(String)` | 字符串发送，以 `'\0'` 结尾 |
| `USART1_SendNumber(Number, Length)` | 数字按十进制逐位转字符发送，如 `(1234, 4)` → `"1234"` |
| `USART1_Printf(format, ...)` | 格式化发送（vsnprintf 实现，最多 128 字节），用法同 printf |
| `USART1_Recv()` | 阻塞式查询接收单字节（与中断接收二选一，勿同时使用） |
| `fputc()` | printf 重定向到 USART1（需勾选 MicroLIB） |
| `USART1_IRQHandler()` | 中断服务函数：逐字节存入缓冲区，IDLE 判定一帧结束置 `flag` 并回显 |

---

## 4. delay（delay.c / delay.h）— 阻塞延时

无引脚占用。基于 `__nop()` 指令延时，按系统主频 72MHz 校准。

| 函数/宏 | 功能 |
|---------|------|
| `Delay_nus(time)` | 微秒级阻塞延时 |
| `Delay_nms(x)` | 毫秒级阻塞延时（宏，内部调用 `Delay_nus(x*1000)`，注意 x*1000 勿超过 uint32 上限约 4294967ms） |

---

## 典型初始化流程

```c
int main(void)
{
    LED_Config();          // 指示灯初始化
    KEY_Config();          // 按键初始化
    USART1_Config(115200); // 串口初始化，波特率 115200

    while (1)
    {
        // 按键检测 / 串口帧处理 / 指示灯逻辑
    }
}
```
